# Jarvis Voice Assistant

Jarvis is a Python-based voice assistant that listens to user voice input, processes queries, and returns spoken or text-based responses using external APIs.

This project demonstrates practical usage of speech recognition, API integration, and modular Python development.

---

## Features
- Voice input using microphone
- Speech-to-text conversion
- Wikipedia-based knowledge search
- Text-based responses (voice output can be added)
- Modular and extensible architecture

---

## Tech Stack
- Python 3.13
- SpeechRecognition
- Wikipedia API
- Git & GitHub for version control

---

## Installation

### 1. Clone the repository
```bash
git clone https://github.com/mruniverse11/Jarvis.git
cd Jarvis

Install dependencies
pip install -r requirements.txt
```

## Usage

Run the main application:

python main.py

Speak your query when prompted. Jarvis will process the input and return relevant information.
